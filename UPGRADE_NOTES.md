# CoBest v0.2 — Product Decisions

## What we learned from Warhead

Warhead demonstrates the value of separating CMS/content, visual design, responsive controls, ecommerce, users, themes, and publishing inside one website platform.

## What we learned from Shopify

Shopify's landing experience leads with the business outcome, shows the product in context, explains major benefits in simple groups, repeats the primary CTA, and builds confidence through ecosystem/support information.

## CoBest's position

CoBest should not copy either product. Its distinct starting point is:

> Other builders begin with the canvas. CoBest begins with the business.

The core flow is:

**Discovery → Brief → Website → Content → Commerce → Publish**

## Prototype architecture

- Project: onboarding and website brief
- Website: pages, visual editor, storefront preview
- Content: media and assets
- Commerce: products, orders, customers
- Insights: analytics

Only the modules required to test the core prototype are functional today. Planned modules are deliberately labeled as planned.
